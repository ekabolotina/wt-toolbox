# wt-toolbox

---

Расширение для отладки веб-терминала.

## FE Messages

В DevTools доступна вкладка **FE Messages**. При её выборе автоматически открывается
просмотр сохранённой истории. Запись включается отдельно; открытие самого DevTools
без выбора FE Messages не подключает recorder и IndexedDB терминала.
Вкладка следует светлой или тёмной теме DevTools, включая переключение темы на лету.
При открытии сообщения размер массива `data` виден как `Array(N)` ещё до раскрытия;
worker подсчитывает элементы порциями, в интерфейс сам массив не загружается.
Служебный опрос состояния поддерживает связь во время просмотра. При временном
разрыве канала фильтры, выбранное сообщение и раскрытые узлы сохраняются.

Поддерживается терминал со сборкой ADIRWEB-3127 и API `aDebug.feViewer`.
Фильтры, дерево JSON, сегменты массивов, поиск, подсветка, копирование, JSONL и удаление
сеансов используют тот же интерфейс, что и консольная панель.

Один просмотрщик может владеть подключением к странице: перед переходом из консольной
панели в DevTools остановите запись и закройте панель. История остаётся общей.
«Перезагрузить и начать запись» включает запись до первых сообщений нового документа;
DevTools переподключается автоматически. Закрытие DevTools останавливает запись
и освобождает worker. Если связь потеряна во время перезагрузки, запись автоматически
завершается после 15 секунд без запросов владельца. Переключение на другую вкладку DevTools
само по себе запись не останавливает.

Поддерживаются основные стенды, `local.invest.alfabank.ru`,
`local.invest-test.alfabank.ru`, localhost и 127.0.0.1.

Интерфейс включён в `src/vendor/feViewer.js`, выполняемый код с сервера терминала
в расширение не загружается. Worker, поиск и БД остаются на стороне inspected page;
через мост передаются только команды и ограниченные результаты. Копирование
использует разрешение `clipboardWrite`; чтение буфера обмена не запрашивается.

### Обновление общего интерфейса

Из корня checkout Terminal с актуальной реализацией выполните:

```sh
node scripts/build-fe-viewer.mjs ../wt-toolbox
```

Команда использует установленный Vite из Terminal и пересобирает только интерфейс
в `src/vendor/feViewer.js`. Сгенерированный файл не редактируется вручную.
После изменения протокола обновляйте обе стороны интеграции; несовместимая сборка
терминала отображает ошибку подключения.

### Локальный запуск

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm run build
```

В `chrome://extensions` включите режим разработчика и загрузите распакованное
расширение из корня репозитория или `dist`. После обновления расширения
переоткройте DevTools проверяемой вкладки.

### Проверки

```sh
corepack pnpm test
corepack pnpm run lint:js
corepack pnpm run lint:css
```

Тест проверяет закрытие покинутого соединения и восстановление канала во время
незавершённого закрытия старого владельца.
