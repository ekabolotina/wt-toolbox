# wt-toolbox

Расширение для отладки веб-терминала.

## FE Messages

Вкладка **FE Messages** в DevTools открывает историю автоматически; запись включается
отдельно кнопками «Начать запись» и «Перезагрузить и начать запись». Требуются Chrome 116+
и терминал с capture API `aDebug.feViewer` версии 2 из ADIRWEB-3127.
Консольной панели поверх терминала больше нет.

История, поиск, дерево JSON и экспорт работают в worker расширения. IndexedDB принадлежит
расширению, поэтому сеансы доступны из разных вкладок и стендов; в списке указан origin.
Страница отвечает только за включаемый по запросу транспортный захват.
Она не открывает БД для FE Messages и не загружает интерфейс или поиск.

Пачки передаются фрагментами по 16 384 символа. Финальный ACK освобождает очередь страницы
только после сохранения в IndexedDB расширения. Номер пачки сохраняется атомарно с сообщениями,
поэтому повтор доставки не дублирует данные. `ConnectionKey` скрывается до передачи.
Скрытый документ расширения обслуживает storage worker и досохраняет очередь при закрытии
DevTools. После завершения закрываются workers и подключения БД; история остаётся на диске.

Доступны фильтры и их очистка одной кнопкой, дерево JSON, ленивые сегменты массивов,
поиск в выбранном сообщении, подсветка, копирование JSON объектов, экспорт JSONL,
удаление одного или всех сеансов. `Array(N)` у корневого `data` виден до раскрытия;
сам массив не загружается в интерфейс целиком. Тема следует DevTools.
Навигация не перемонтирует просмотрщик. Посторонняя навигация завершает текущую запись;
кнопка reload запускает новый сеанс до первых IN/OUT нового документа.
Переключение на другую панель DevTools запись не останавливает.

Лимит истории — 2 GiB JSON. До 64 MiB выделено транспорту, до 64 MiB — очереди передачи
страницы и до 64 MiB — сборке в расширении; это не ограничение всего JS heap.
Ошибка БД, worker или переполнение останавливают запись с явной причиной.
Прерванные при сбое расширения сеансы помечаются при повторном открытии.
Расширение запрашивает `offscreen`, `unlimitedStorage` и `clipboardWrite`;
чтение буфера обмена не требуется. Старая история страницы автоматически не импортируется.

Поддерживаются основные стенды, `local.invest.alfabank.ru`,
`local.invest-test.alfabank.ru`, localhost и 127.0.0.1.

### Исходники просмотрщика

UI, изолированный CSS, поиск и IndexedDB находятся в `src/fe` и выполняются как обычные
ES-модули. `src/fe/history.worker.js` работает только в origin расширения. Checkout Terminal,
Vite и генерация vendor-bundle для сборки расширения больше не нужны.
Существующий `idb` 7.1.1 включён в `src/vendor/idb` вместе с лицензией без изменений.
Код включён в пакет расширения; удалённый исполняемый код не загружается.
Изменения capture API требуют совместимого обновления обеих сторон.

### Локальный запуск

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm run build
```

В `chrome://extensions` включите режим разработчика и загрузите расширение из корня
репозитория или `dist`. После обновления переоткройте DevTools проверяемой вкладки.

### Проверки

```sh
corepack pnpm test
corepack pnpm run lint:js
corepack pnpm run lint:css
```

Тесты истории и ленивого JSON-просмотра находятся в `scripts/fe`; `expect` и
`fake-indexeddb` перенесены вместе с ними как зависимости только для разработки.
Тесты также защищают восстановление владельца, запоздалое закрытие и подключение,
ожидание cleanup перед новым сеансом, отложенную навигацию собственной перезагрузки,
сохранение ошибки Stop и повторное открытие после неуспешного закрытия.
